# 03 · 成本与预算（BSC 版）

**版本**：v2（Solana → BSC 切换后）　**日期**：2026-10-08
**价格基准**：BNB = $769.24、BSC gas = 0.05 gwei（均为 2026-10-08 实测）

---

## 0. 一句话：换链之后，账变了

| | Solana 版 | **BSC 版** |
|---|---|---|
| 1000 人 gas | $173.84 | **$1.96** |
| 最大成本项 | gas（租金） | **X API** |
| 试点总预算 | ≈ $200–250 | **≈ $30–45** |

**成本结构整个翻转了**：Solana 上 gas 是绝对大头，BSC 上 **X API 反而变成 gas 的 5 倍**。

---

## 1. 单笔发放成本

```
ERC-20 transfer ≈ 51,000 gas
  （21,000 基础 + ~30,000 用于 0→非零的 SSTORE）

51,000 gas × 0.05 gwei = 2,550 gwei = 0.00000255 BNB ≈ $0.00196
```

**对比 Solana 的 $0.17384 —— 便宜 89 倍。**
根因：Solana 每人要新建 token 账户、固定收 1,488,440 lamports 租金；
**EVM 没有账户租金这个概念。**

### 敏感度（gas 涨价也不影响结论）

| BSC gas | $/人 | 1000 人 |
|---|---|---|
| 0.05 gwei（当前） | $0.00196 | $1.96 |
| 0.5 gwei（10 倍） | $0.0196 | $19.60 |
| 1 gwei（20 倍） | $0.0392 | $39.20 |
| 5 gwei（100 倍） | $0.196 | $196 |

**要涨到 100 倍才会追平 Solana 的成本。** 这不是常规定价风险。

| 项 | 金额 | 说明 |
|---|---|---|
| gas（1000 次 transfer） | **$1.96** | |

| 域名 | ~$10/年 | |

| 数据库（Neon / Supabase 免费档） | **$0** | 外部 Postgres，不用 D1 |
| 签发进程 | **$0** | 本机批处理，每天一次 |
| 设计 / 素材 / 内容 | 你的时间 | |
| **合计** | **≈ $45 – 60** | |

> **托管成本已经压到接近零**（原方案 VPS $5–20/月 → 现在 $0）。
> 代价见 ADR-0002：发放依赖你每天记得跑脚本，需要配提醒 + 积压告警。

> **X API 现在是绝对主导成本（约 $20），gas 只占 3%。**
> 这个结构的含义：**扩规模时瓶颈在 X API，不在链上。**

### 热钱包充值建议

**充 0.1 BNB（≈ $77）**：

- 实际只需 0.00255 BNB（$1.96），充 0.1 是留了 **约 40 倍缓冲**，防 gas 暴涨
- 设 `MAX_GAS_SPEND_WEI = 0.05 BNB`（≈ $38）——**即使 gas 涨 20 倍也发得完，且物理上花不超上限**
- 这个钱包视同**可烧毁**，不与其他资金同钱包
- **比起 Solana 版要充 2.5 SOL（$292），风险敞口小了 3.8 倍**

## 5. 容易被忽略的成本

1. **机会成本**：如果用代币结算任何本可以收现金的商品或服务，等于放弃那部分现金收入。
   代币本身几乎零成本，但**被它替换掉的收入不是**。只有边际需求为零的数字权益才适合用代币兑换。
2. **人工成本**：反滥用复核、异常取消、客服答疑。试点期预计每天 30–60 分钟。
3. **法律/合规成本**：升级为公司主体（L3）时需隐私政策、服务条款、合规评估。
4. **放弃的收入**：做这件事的时间本可以用于卖课/接单。**这是最大的一笔隐性成本**——
   它比上面所有显性成本加起来都大得多。

## 6. 不花的钱（明确列出）

| 项 | 为什么不花 |
|---|---|
| 买粉 / 刷量 | 没有转化价值，且**链上取证能一眼看穿**——本项目的全部设计都建立在可验证之上 |
| 付费投流 | 转化率未知时投了算不出 ROI；且付费流量里刷量工作室占比高，会直接烧掉 gas 预算 |
| KOL 分成推广 | 本轮不做 |
| 上 DEX 建 LP | 本轮不做（见文档 04 合规） |

## 7. 回本判断

**花约 $35–45，换到 1000 个真实钱包地址 + 一次可验证的公开交付记录。**

回本条件：这 1000 人里只要有一小部分真的使用了你发放代币所对应的任何东西。

> **成本已经不是这个项目的门槛。** $35 换 1000 个真实用户，按任何标准都便宜。
>
> **所以判断它成不成立，不取决于成本，而取决于交付之后有没有人真的用它。**
> 如果 1000 人领完、兑换率接近 0，那问题在需求端，不在成本或技术。
> 这不是靠优化 gas 能修的。
