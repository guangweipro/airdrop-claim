## 0. 前置：架构不变量自检（本项目特有，最重要）

发布前逐条确认代码里**不存在**下列能力。这是本项目区别于"发币工具"的根本：

- [ ] **I1** 全仓库**无任何收款/支付/资金归集代码**——无预售、无支付接口、无托管地址常量
- [ ] **I2** 无任何可配置的虚假展示组件（假进度条 / 假买单滚动条 / 假倒计时）
- [ ] **I3** 所有对外统计均来自数据库实时查询（**无写死的数字**）
- [ ] **I4** `txHash` 强制入库，且提供公开导出接口
- [ ] **I5** SIWE 签名校验**不可通过配置关闭**

### 管理后台专项（开源前必查）

- [ ] **`ADMIN_ENABLED=false` 是默认值**（`ADMIN_ENABLED` 不设或为 false 时 `/admin/*` 全部 404）
- [ ] `adminAddress` 在 `.env.example` 里是**占位符，不是真实地址**
- [ ] 管理后台**不放在首页导航**里，也没有任何公开入口链接
- [ ] 管理后台**无提款/转账功能**（`grep -rniE "withdraw|transferOut|sweep" src/app/api/admin/` 应为空）
- [ ] 管理后台**不能修改 `/api/stats` 的任何数字**
- [ ] README 明确写出：**启用管理后台前必须自行加上认证并替换 `adminAddress`**

> 自检方法：`grep -rniE "pay|deposit|presale|contribute|treasury|progress.*fake|mock" src/` 逐条人工确认。

## 1. 密钥与敏感数据（**最高优先级**）

- [ ] **全历史密钥扫描**：`gitleaks detect --log-opts=--all`（**不是只扫当前文件**）
- [ ] 自定义 gitleaks 规则已覆盖本项目的密钥形态：
  - [ ] `0x` + 64 位十六进制（EVM 私钥）
  - [ ] keystore JSON（`{"address":...,"crypto":...}`）
  - [ ] BscScan API key、X API client secret
- [ ] 仓库内**不存在**以下真实值（逐项人工确认）：

| 项 | 确认 |
|---|---|
| 热钱包地址 | [ ] 不存在 |
| 部署后的合约地址 | [ ] 不存在 |
| X API 凭证 / client secret | [ ] 不存在 |
| 数据库连接串 | [ ] 不存在 |
| 真实的运营阈值（限流值 / 上限 / 分级倍数） | [ ] 已替换为通用默认值 |
| 真实活动推文 ID / X 账号 ID | [ ] 不存在 |
| 真实用户数据（钱包地址 / X ID） | [ ] 不存在，含测试固件与截图 |

- [ ] `.env.example` **只有键名**，无任何值
- [ ] `.gitignore` 覆盖 `.env*`、keystore、`*.local.json`
- [ ] 若历史上曾误提交过密钥 → **先轮换密钥，再重写历史**（顺序不可颠倒）
